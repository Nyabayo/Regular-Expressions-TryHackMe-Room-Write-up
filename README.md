# Regular Expressions TryHackMe Room Write-up
<img width="1490" height="351" alt="image" src="https://github.com/user-attachments/assets/dd87ec44-25c8-4242-9c56-634861327217" />

This repository covers the **Regular Expressions (Regex)** TryHackMe room, which focuses on helping users learn and practice regex. It provides in-depth explanations and solutions to the various tasks and challenges in the room, including the following:

## Task 1: Introduction
Introduction to regular expressions, including their utility and how they make pattern searching easier.

## Task 2: Charsets
Learn about using character sets (charsets) to match specific characters or ranges, and how to exclude characters from a set.

## Task 3: Wildcards and Optional Characters
Explore the use of the dot `.` wildcard to match any character and the question mark `?` to make characters optional.

## Task 4: Metacharacters and Repetitions
Introduction to metacharacters like `\d`, `\w`, and `\s`, and using repetition operators like `{}`, `*`, and `+` to match multiple characters.

## Task 5: Starts with/Ends with, Groups, and Either/Or
Learn how to use `^` for "starts with", `$` for "ends with", and groups with parentheses `()` and the "either/or" operator `|`.

## Task 6: Conclusion
Summary of the importance and power of regular expressions in various fields, especially in cybersecurity tasks like Capture the Flag (CTF) challenges.
